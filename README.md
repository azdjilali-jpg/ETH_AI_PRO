ETH AI PRO Android
==================
مشروع Android مستقل مخصص لـ ETHUSDT / 5 دقائق.

هذه نسخة أولية مستقرة للواجهة والاتصال المباشر بـ Binance.
مهم: النسخة الحالية تعرض إشارة أولية من بيانات الشموع وليست نموذج ML كاملًا.
لإضافة نموذج ML محلي قوي، يمكن لاحقًا تضمين نموذج ONNX/TFLite مدرب خارج الهاتف.

البناء:
- Android Studio
- Gradle
- افتح مجلد المشروع ثم Build APK.
